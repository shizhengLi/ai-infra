# L20 optimization notebook

This directory is the durable record for Mini-SGLang optimization on 8 x NVIDIA L20.

## Documents

- `grok.md`: initial project assessment and candidate directions.
- `l20_optimization_plan.md`: measurement rules, technical roadmap, and success criteria.
- `progress.md`: current state, decisions, and next experiment.
- `experiment_template.md`: required structure for every new experiment.
- `experiments/`: numbered experiment notes and machine-generated benchmark reports.

An optimization is accepted only when its hypothesis, exact command, environment, raw result,
interpretation, and regression coverage have been recorded in Markdown.
